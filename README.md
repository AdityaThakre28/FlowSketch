# FlowSketch

**Visual Workflow & Software Architecture Builder**

FlowSketch is a visual design tool for creating, connecting, and documenting software workflows and system architecture through an interactive canvas.

Design your ideas visually, organize system components, and turn complex processes into clear diagrams.

## Features

- **Visual Canvas** — Create and arrange workflow and architecture diagrams.
- **Drag-and-Drop Components** — Add process, decision, API, database, and other components.
- **Node Connections** — Connect components to represent workflows and system interactions.
- **Properties Inspector** — Customize component names, descriptions, and notes.
- **Diagram Persistence** — Save and restore diagrams using browser local storage.
- **Import & Export** — Exchange diagram data through JSON and export diagrams as PNG.
- **Clean Interface** — A minimal workspace designed for clarity and productivity.

*Ensure each feature listed above is implemented and working in the current version.*

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/AdityaThakre28/FlowSketch.git
cd FlowSketch
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
